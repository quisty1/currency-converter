# FX Multi

Modern currency converter that converts one amount into several fiat and crypto currencies at once.

## Stack

- React 19, Vite and strict TypeScript
- TanStack Query for remote rates and cache lifecycle
- Zustand for persisted user settings
- Material UI with light, dark and system color modes
- A small typed dictionary exposed through React Context
- Zod validation at both external API boundaries
- Vitest, Testing Library, MSW, Playwright and axe
- Installable PWA generated by `vite-plugin-pwa`

## Commands

```bash
npm run dev
npm test
npm run test:coverage
npm run test:e2e
npm run test:a11y
npm run lint
npm run build
npm run check
```

Playwright browsers must be installed once with `npx playwright install chromium` before running E2E tests.

## Architecture

`src/domain` contains pure conversion logic and types. `src/api` owns external providers and runtime validation. TanStack Query owns rates; Zustand owns amount, base currency, targets, locale and theme. `src/i18n` contains the application dictionary and locale-aware formatting.

The v1 `fx-multi-state` local-storage value is read on first launch, so existing settings are retained. Its legacy rates cache is migrated to the dedicated `fx-multi-rates` entry.
